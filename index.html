Tambah Model 3D Jakarta (.GLB)

Anda dapat menambahkan model 3D bangunan nyata Jakarta apa saja ke dalam website ini secara 100% gratis melalui 2 cara:

⚡ Cara 1: Tarik & Lepas Langsung (Drag & Drop)

Cukup tarik file .glb atau .gltf dari komputer Anda dan lepas langsung ke jendela browser ini. Model akan langsung dirender seketika di dekat Bundaran HI!

💾 Cara 2: Simpan Permanen di Proyek

  1. Simpan file model 3D Anda di folder: public/models/nama-gedung.glb
  2. Buka file src/config/landmarks.js
  3. Tambahkan nama, posisi koordinat, dan ketinggiannya ke dalam daftar landmark.

🌐 Sumber Model 3D Gratis Kota Jakarta

  • • Sketchfab.com: Cari "Jakarta building" atau "Monas" dengan filter Free Download / CC-BY format .GLB.
  • • OpenStreetMap via BlenderGIS: Ekstrak footprint gedung nyata Jakarta langsung dari GIS gratis dan ekspor ke .glb.
  • • Poly Pizza / 3D Warehouse: Ribuan aset arsitektur gratis siap pakai.
