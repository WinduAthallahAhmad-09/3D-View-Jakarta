Integrasi Model 3D Jakarta (.GLB)

Website ini mendukung pemuatan file model 3D nyata bangunan Jakarta secara 100% gratis tanpa batasan API:

METHOD 01 · DRAG & DROP SEKETIKA

Tarik file .glb dari komputer Anda dan lepaskan langsung ke jendela browser. Model langsung dirender di koridor Jakarta.

METHOD 02 · SLOT DIREKTORI PERMANEN

Simpan berkas pada folder public/models/nama-gedung.glb, lalu daftarkan koordinatnya di src/config/landmarks.js.

DATA SOURCE · REPOSITORI GRATIS
  • Sketchfab: Filter CC-BY (Gratis) format .GLB untuk gedung-gedung Jakarta.
  • BlenderGIS: Unduh koordinat dan tapak gedung 3D satelit OpenStreetMap Jakarta secara otomatis.

Google Photorealistic 3D Tiles

Stream Seluruh Kota Jakarta Asli dari Satelit Google Earth

Tersimpan aman secara lokal di browser Anda (localStorage).

CARA MENDAPATKAN API KEY GRATIS $200 CREDIT/BLN
  1. Buka Google Cloud Console dan login akun Google.
  2. Buat Proyek baru (misal: Jakarta-3D).
  3. Di menu APIs & Services, cari dan aktifkan Map Tiles API.
  4. Masuk ke Credentials ➔ Create Credentials ➔ API Key.
  5. Salin API Key tersebut dan tempel ke kolom di atas.
